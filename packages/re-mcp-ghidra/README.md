# re-mcp-ghidra

The Ghidra server of [ghidra-mcp-next](https://github.com/coffeegrind123/ghidra-mcp-next):
a headless Ghidra MCP server on pyghidra, with atomic batches, Python execute against the
Ghidra API, projects and Ghidra Server version control. Commands: `ghidra-mcp-next`
(alias `re-mcp-ghidra`) and the worker `re-mcp-ghidra-worker`.

Needs Python 3.12+, Ghidra 12+ and JDK 21. Installation, configuration and the tool list
are in the [main README](https://github.com/coffeegrind123/ghidra-mcp-next#readme) and
[docs/tools.md](../../docs/tools.md).
